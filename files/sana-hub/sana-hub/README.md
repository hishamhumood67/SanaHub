# SANA HUB

**Where Saudi Makers Build the Future** · صنع في السعودية · هَبْ الهندسة التفاعلية

Bilingual (English / Arabic, full RTL) 3D electronics and robotics playground with live circuit
checking (SANA AI) and a community gallery where makers share and remix circuits.

```bash
npm install
npm run dev        # http://localhost:3000/playground
npm run typecheck
```

Start with [`CODE_OVERVIEW_GUIDE.md`](./CODE_OVERVIEW_GUIDE.md): it explains every file.
